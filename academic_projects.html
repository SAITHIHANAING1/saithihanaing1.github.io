School projects

Coursework from the Diploma in Applied AI & Analytics at Nanyang Polytechnic.

  • SafeStep

    In progress

    Epilepsy support platform with modules for login, seizure monitoring, safety zones, caregiver training and predictive reporting. Safety zones are drawn on a Leaflet map, and live vitals and risk forecasts are charted with Chart.js. Data lives in cloud PostgreSQL with strict validation. Designed first in Figma, then built in a GitHub monorepo with one branch per module and pytest running in GitHub Actions.

    Code ↗

    Flask · Jinja2 · PostgreSQL · Bootstrap 5 · Leaflet.js · Chart.js · GitHub Actions

  • Pedal&Co data story

    Blended sales, inventory, brand and staff data into four interactive Tableau dashboards with filters, parameters and calculated fields. Found a 48% peak repeat-customer rate, a 45% revenue spike from flash sales, SKU imbalances and the top-performing staff, and turned them into nine recommendations.

    Tableau · data blending · calculated fields

  • Inventory management CLI

    Command-line tool to create, read, update and delete products, with search by ID and filters by category. Ships with 50 sample products, and every input is validated so bad data never reaches the store.

    Python
