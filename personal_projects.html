Personal projects

Things I built on my own time, including two bots I use myself.

  • Finance bot

    Telegram bot for tracking expenses. A local LLM (Qwen 2.5 on Ollama) reads messages like "grab 12.40" and files them in SQLite. Two users, each with their own database, currency and timezone, plus an admin role. The language model runs on my own machine, not in the cloud.

    Python · Ollama · SQLite · Telegram API

  • LinkedIn post assistant

    I send rough notes and photos to a Telegram bot. It drafts a post in my voice with Claude, I ask for changes, and an automatic check looks for typos, confidential details and photo problems. It only posts through the LinkedIn API after I approve, either now or on the weekly schedule.

    Python · Claude API · LinkedIn API · Telegram API

  • F1 2025 Singapore GP analysis

    Collected lap-time, sector, pit-stop and weather data from the official F1 APIs, cleaned it, and explored it with pandas and SQL. The charts show which tyre strategies paid off and how humidity changed lap times.

    Live app ↗

    Python · pandas · SQL · Matplotlib · Streamlit

  • Photo gallery

    Photo sharing app with multi-file upload, search and role-based access. Images are resized in the background with Celery, which halved page-load time.

    Flask · Jinja · SQLite · Celery · JavaScript

  • FlipFun

    Turns a photo from your camera or an upload into black-and-white pixel art with Floyd–Steinberg dithering, then reveals it on a split-flap board that flips row by row. Plain HTML, CSS and JavaScript with no dependencies.

    Code ↗

    JavaScript · Canvas · image processing
